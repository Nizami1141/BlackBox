# Проверка всех модулей на одной ESP32-S3

Этот стенд относится к Freenove/Goouuu ESP32-S3 с OV5640. Он использует
старую схему с **одной** S3; карта GPIO отличается от двухплатной схемы,
где GM67, LCD и W5500 подключены к ESP32-WROOM.

| Устройство | Сигнал | GPIO ESP32-S3 |
|---|---|---:|
| OV5640 | штатный шлейф Freenove/Goouuu | см. `firmware/include/camera_pins.h` |
| LCD с HW-61 | SDA / SCL | 47 / 21 |
| GM67 | TX сканера → RX S3 / RX сканера ← TX S3 | 1 / 2 |
| Кнопка | вывод 1 / вывод 2 | 14 / GND |
| W5500 | SCK / MISO / MOSI / CS / RST | 39 / 40 / 38 / 41 / 42 |
| Все устройства | GND | общая земля |

При использовании W5500 вынуть SD-карту: пины 38–40 делят с ней шину.
HW-61 и конкретный W5500 из этого проекта питаются от 5 В. Если HW-61
питается от 5 В, SDA/SCL должны идти через двунаправленный преобразователь
уровней 3.3↔5 В. Выход TX GM67 должен быть 3.3 В; если в покое на нём 5 В,
нужен делитель/преобразователь перед GPIO1. Питание OV5640 задаётся самой
камерной платой/шлейфом; не подавайте 5 В на вывод питания голого сенсора.

## USB-C Breakout

Измерьте мультиметром VBUS–GND на breakout **до** соединения с устройствами.
Подавайте проверенные 5 В на вход 5V/VIN платы и 5-вольтовые входы модулей,
объедините земли. Не подавайте VBUS на 3V3. Ток источника должен покрывать
одновременную работу ESP32-S3, OV5640, W5500, GM67 и подсветки LCD.

Для COM9 нужен USB-канал CH343 к ноутбуку. Если плата одновременно получает
5 В от внешнего breakout и от USB ноутбука, проверьте схему развязки питания
именно вашей платы; без неё нельзя связывать два источника 5 В. Для стенда
можно пользоваться кабелем данных с отключённым VBUS при внешнем питании.
Прошивка не измеряет напряжение и не может подтвердить качество питания.

## Запуск

На сетевой карте ноутбука, соединённой с W5500, установите
`172.16.6.51/24` без шлюза. W5500 использует `172.16.6.52/24`.
Не назначайте один IP двум сетевым интерфейсам ноутбука.

В каталоге `firmware` прошейте плату:

```powershell
pio run -e s3_all_hardware_test -t upload --upload-port COM9
```

В первом окне терминала запустите Ethernet-ответчик:

```powershell
conda activate ml
python tools\ethernet_echo_test.py
```

Во втором окне откройте Serial Monitor:

```powershell
pio device monitor -e s3_all_hardware_test -p COM9 -b 115200 --rts 0 --dtr 0
```

Если Ethernet-ответчик запущен после платы, в Serial Monitor отправьте
`ETHTEST` и Enter. Для полной проверки нажмите и отпустите кнопку, затем
поднесите любой штрихкод к GM67. Прошивка повторно включает сканирование
каждые 6 секунд до получения кода. Команда `STATUS` печатает итог;
`RUN` повторяет автоматические проверки. Успешный итог:

```text
[PASS] ETHERNET W5500 SPI + link + PC PING/PONG
[PASS] GM67 UART command + barcode
[PASS] BUTTON GPIO14 real press
[PASS] LCD I2C ACK + write, addr=0x27
[PASS] CAMERA sensor + complete JPEG
RESULT: PASS 5/5
```

LCD покажет `ALL TESTS PASS`. Проверка LCD подтверждает обмен с HW-61 по I²C;
видимые символы и контраст нужно также проверить глазами. Камера проверяется
по действительному JPEG (начало/конец файла), а не только по PID сенсора.
Этот тест не сохраняет фотографию; для сохранения используйте профиль
`s3_camera_lcd_test` и `tools/camera_lcd_gui.py`.
