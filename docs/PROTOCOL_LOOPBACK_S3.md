# Проверка протоколов и линий ESP32-S3

Профиль `s3_protocol_loopback` проверяет контроллеры и выводы платы без
W5500, GM67, HW-61 и кнопки. Устройство на другом конце линии этим тестом
**не проверяется**. Камера — исключение: SCCB и DVP проверяются с подключённой
OV5640 по действительному JPEG. Её интерфейс уже прошёл предыдущий тест,
так что можно выполнить остальные четыре проверки независимо.

## Прошивка и монитор

Из папки `firmware`:

```powershell
pio run -e s3_protocol_loopback -t upload --upload-port COM9
pio device monitor -e s3_protocol_loopback -p COM9 -b 115200 --rts 0 --dtr 0
```

В мониторе введите `CLEAR` перед новой серией. Результаты каждого этапа
запоминаются во Flash NVS, поэтому питание можно выключать для безопасной
перестановки перемычек. После включения введите команду этапа и `STATUS`.
Команды: `PINS`, `UART`, `SPI`, `I2C`, `GPIO`, `CAM`, `STATUS`, `CLEAR`.

Если `UART` показывает `received=0/5`, с той же перемычкой выполните
`PINS`. Он проверяет GPIO42→GPIO14 простыми уровнями LOW/HIGH. Если и он
провален, сначала исправьте перемычку и проверьте маркировку IO42/IO14 на
ESP32-S3. Если `PINS` пройден, а `UART` нет, исследуйте UART-контроллер.

Если Serial Monitor не принимает клавиатуру, **закройте его через Ctrl+C**
и отправляйте команды из обычного терминала:

```powershell
python tools\protocol_command.py CLEAR
python tools\protocol_command.py CAM
python tools\protocol_command.py UART
python tools\protocol_command.py STATUS
```

Скрипт сам открывает COM9, отправляет команду, печатает ответ и закрывает
порт. Нельзя запускать скрипт одновременно с Serial Monitor: COM9 может быть
открыт только одной программой.

| Команда | Что отключить при выключенном питании | Перемычки перед включением |
|---|---|---|
| `UART` | W5500 и кнопку | GPIO42 → резистор 1 кОм → GPIO14 |
| `SPI` | W5500; также вынуть SD-карту | GPIO38 → GPIO40 |
| `I2C` | LCD HW-61, W5500 и кнопку | GPIO47 → GPIO14 (SDA), GPIO21 → GPIO42 (SCL) |
| `GPIO` | кнопку и W5500 | GPIO42 → резистор 1 кОм → GPIO14 |
| `CAM` | ничего из линий камеры | OV5640 оставить подключённой |

Перемычки ставить и снимать **только при выключенном питании**. Не соединяйте
линии с 5 В. При I²C-тесте линии должны подтягиваться к 3.3 В; если без LCD
они плавают, добавьте по 4.7 кОм от SDA и SCL к 3.3 В. Для GPIO-теста
резистор 1 кОм ограничивает ток при ошибке подключения.

При успехе каждого этапа выводится `[PASS]`. После всех пяти:

```text
[PASS] UART1 TX GPIO42 -> RX GPIO14 loopback
[PASS] W5500 SPI MOSI GPIO38 -> MISO GPIO40 loopback
[PASS] I2C master GPIO47/21 -> slave GPIO14/42
[PASS] BUTTON GPIO output 42 -> input 14 loopback
[PASS] CAMERA SCCB + DVP actual JPEG
RESULT: PASS 5/5
```

SPI loopback проверяет передачу MOSI→MISO и работу SPI-контроллера. Он не
доказывает состояние W5500, RJ45, линии SCK/CS на разъёме или связь с ПК.
UART loopback не доказывает исправность GM67. I²C loopback не доказывает
исправность HW-61. GPIO loopback подтверждает вход кнопки, но не её контакт.
Для проверки именно модулей используйте `s3_all_hardware_test`.
