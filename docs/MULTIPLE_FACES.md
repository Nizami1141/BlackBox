# Несколько лиц в кадре AKS

Прошивка выбирает среди лиц с `match: true` человека с наибольшей
схожестью. Сначала используется `user.similarity`, затем `similarity`,
затем `score`. При равенстве или отсутствии оценок выбирается первый
распознанный человек в порядке ответа сервера.

Имя, фамилия, `log_id` и срок сессии берутся из одного выбранного объекта.
На LCD показывается его имя; последующий штрихкод связывается с его
`log_id`. Отдельная запись груза для остальных лиц не отправляется.

Если распознанных людей нет, остаётся обычный отказ. Неверный формат
ответа или отсутствующий положительный целочисленный `log_id` у
распознанного лица остаются ошибками; доступ по `match: false` не выдаётся.

Основная сборка запускается из корня `cc2`: `esp32s3cam_baku`.
Тест `tests/aks_face_selection_test.cpp` использует установленный ArduinoJson
и проверяет выбор человека, соответствие имени и сессии, отказы и ошибки.
