ESP32-S3 CAM / PlatformIO — 26.10.2026

1. Распакуйте ZIP целиком. В VS Code выберите File -> Open Folder
   и откройте папку firmware, в которой находится platformio.ini.
2. Установите расширение PlatformIO IDE, если оно отсутствует.
   При первой сборке нужен интернет для загрузки платформы и библиотек.
3. Откройте терминал PowerShell в этой папке:
   $pio = "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe"
   & $pio device list
4. Подключите плату через USB-UART. Установите официальный драйвер CH343,
   если Windows не создала COM-порт. Номер порта на другом ПК может измениться.
   В командах ниже замените COM9 на фактический порт.
5. Закройте Serial Monitor перед загрузкой. Тестовый профиль Баку:
   & $pio run -e esp32s3cam_baku -t upload --upload-port COM9
6. Если требуется ручной вход: держите BOOT, коротко нажмите и отпустите
   RST. При Connecting продолжайте держать BOOT; отпустите после начала
   Writing. RST не должен оставаться нажатым.
7. После SUCCESS откройте журнал:
   & $pio device monitor -e esp32s3cam_baku --port COM9 --baud 115200 --dtr 0 --rts 0
   Выход из монитора: Ctrl+C.

Для полевой сети Товуза загрузите другой профиль:
   & $pio run -e esp32s3cam_tovuz -t upload --upload-port COM9

Сетевые параметры:
Баку:  IP 172.16.5.193,   маска 255.255.0.0,   шлюз 172.16.0.1.
Товуз: IP 172.20.204.193, маска 255.255.255.0, шлюз 172.20.204.1.
Общий DNS: 192.168.250.248.
По умолчанию выбран Баку. Адрес назначения: aks.customs.gov.az:443.

Включены исходники текущего прототипа: камера QSXGA 2560x1920,
JPEG quality 8, поворот 180 градусов, окно штрихкода 15 секунд.
Тайм-аут штрихкода возвращает систему в ожидание без ESP.restart().

Добавлена диагностика serial-diag-button-net-2026-10-26. Сводка узлов — каждые 10 с.
В мониторе введите STATUS и нажмите Enter для немедленного отчёта.
Для повторной проверки LCD без нажатия RST введите LCDCHECK и нажмите Enter.
При успехе появится LCD TEST OK, при неудаче — подробный блок [lcd].
Команда разрешена в состоянии idle и не запускает проверку лица/запрос в AKS.
Цепочка: кнопка -> камера -> AKS -> GM67 -> AKS -> LCD.
Лог содержит этап, номер проверки, время и результат каждого прохода.
Подробности: docs/SERIAL_DIAGNOSTICS.md.

Исправления 26.10.2026, версия prototype-5mp-q8-scan15-sites-button-net-2026-10-26:
- отпущенный вход должен быть стабильным 150 мс перед новым нажатием;
- LOW при загрузке и отпускание после удержания >=2 с не запускают проверку;
- после любой проверки сбрасываются накопленные нажатия;
- переходы кнопки edge=DOWN/UP выводятся сразу в idle; опрос каждые ~10 мс;
- потерянные IP, шлюз и маска W5500 восстанавливаются даже при link=UP;
- если конфигурация не читается обратно, съёмка не запускается (NETWORK_ERROR).

По журналу 26.10 камера получает снимки, LCD отвечает на 0x27,
но W5500 показывает 0.0.0.0. Это блокирует подключение до отправки в AKS.
На отсоединённом GPIO14 сообщался LOW: фильтр не доказывает исправность
проводки, питания или GPIO. Физическую причину нужно проверить на плате.
Сборка и автоматические тесты проверены; проверка этого выпуска на плате
ещё не выполнена. Подробнее: docs/BUTTON_NETWORK_FIX.md.
